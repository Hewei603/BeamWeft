# 换一幅完整全息图后，能否预测相机看到的变化？

Wojcik 等人在剑桥大学的固定光学台架上，用相位型空间光调制器（SLM）把同一辐条靶投到相机上。本基准只用编号 0 的相机采集确定配准，然后给计算程序换上编号 3 的实际驱动图。在首次打开 3 号采集前，已冻结其预测和判据。该比较检验同一台架上换整幅输入时，一阶衍射图样能否跟随变化。[实验数据与 CC BY 4.0 许可](https://doi.org/10.17863/CAM.121345) · [实验论文](https://doi.org/10.1038/s41598-025-32903-0)

## 测得什么

| 预先约定的检验 | 结果 |
| --- | --- |
| 留出图样的整体形状。固定相机区域内，预测与实测的 Pearson 相关系数至少为 0.80 | **0.94070**。直接沿用训练照片为 0.88819 |
| 输入变化的预测。将模型预言的变化加到训练照片上，与直接沿用训练照片相比，固定内圆的 RMS 误差至少降低 5% | RMS 从 0.63971 降到 0.31395，**降低 50.92%**。预测与实测变化的相关系数为 0.93041 |

RMS 的单位是所选区域平均强度的倍数。两个判据均达标。输入 0 和 3 共用光源、靶图、相机与光学件，只有一个留出的完整设置。这是一项条件明确的外部台架检验。绝对功率、改动镜距后的性能、任意靶图和其他独立设备仍需专门实测。[揭盲回执](observed.json)

## 数据与冻结

- **原件。** Apollo 的 `published database.zip` 有 377,218,383 字节。程序验证发布方 MD5 和本次固定副本的 SHA-256，只从 ZIP 中读取点名的成员。归档的 `data/image_correction/f6cm_exact/info.txt` 记载 0 为未校正全息图，3 为根据实测幅相校正的全息图。同一目录含 0–8 共九组。仓库只收录代码、校验值与统计回执。[作者固定版本的控制程序](https://github.com/antoni-wojcik/hololab_wavecorr/tree/05234cfa9d71e893747621d9dce0a044983ec5ba)
- **光学量。** 光源波长 658 nm，傅里叶镜标称焦距 60 mm；SLM 有 1,920 列 × 1,200 行，像素间距 8 µm，表面相对观察方向约倾斜 25°。相机有 1,440 列 × 1,080 行，像元间距 3.45 µm。`holo_#.npy` 是实际显示的 uint16 灰度，取值 0–1023。对应相位以 2π/1024 rad 每级换算，统一相位常数对强度无影响。`amp_wavefront.npy` 是相对线性振幅；`phase_wavefront.npy` 是展开的弧度相位。它们来自作者的同台分块校准和重建。[实验参数与光路图](https://doi.org/10.1038/s41598-025-32903-0) · [全息驱动生成](https://github.com/antoni-wojcik/hololab_wavecorr/blob/05234cfa9d71e893747621d9dce0a044983ec5ba/experiments/display_hologram.py)
- **几何。** 作者 `aft_matrix.npy` 的方向为相机坐标到目标图坐标，来自标记点配准。随附控制程序没有指明归档中用哪一幅采集完成该配准。本基准单独使用训练图 0 拟合平移、轴缩放与小角度旋转。它也用图 0 判定保存相位与显示相位的相对号，选择负号时训练相关为 0.94329，另一号为 0.89251。计算采用带该有效校准波前的标量傅里叶变换。目录名 `f6cm_exact` 与同目录实验说明中“相机向镜头偏移”的记载不一致，故保留标称焦距和实测配准。该有效波前可能已包含静态离焦与像差，计算中不再叠加离焦或反射倍程。[作者的配准方向](https://github.com/antoni-wojcik/hololab_wavecorr/blob/05234cfa9d71e893747621d9dce0a044983ec5ba/src/calibration/affine_transform.py)
- **计分。** 固定相机矩形为零起始半开区间 x=[430,706)、y=[523,799)，以目标一阶图样为主体。矩形右上角仍可见相邻零级附近的亮斑和条纹，全矩形计分保留这些像素。变化检验使用矩形内以 (568,661) 为中心、半径 103 相机像素的圆。实测先减训练估计的 3 DN 背景，下限截到零。模型按配准映射采样到相机网格，预测与照片分别用 2.5 相机像素标准差平滑，再除以各自矩形的平均强度。这一尺度检验图样结构。未逐像素锁定细尺度散斑。训练和留出区域分别有 4.14% 和 7.15% 像素达到 1022 DN，均保留计入指标。
- **记录。** 2026-11-19 17:54:48 UTC 写入训练输入、计算代码、预测数组及规则的哈希，随后向协作方报送该指纹。17:55:12 UTC 解码 3 号相机数组并计分。原件 ZIP 整体在此前已作字节校验。未用 3 号相机数组决定坐标、平滑、阈值、归一化或模型。这些时间来自运行机器，未使用第三方时间戳服务。[预注册记录](preregistered.json)

## 复算

在仓库根目录使用含 NumPy、SciPy 的 Python 3.11+ 环境，首次下载还需 `curl`。本次使用 Python 3.14.3、NumPy 2.4.6、SciPy 1.17.1。默认缓存为系统临时目录的 `beamweft-fourier-bench`；可向各命令传入相同的 `--cache <目录>`。从空缓存运行这两条，第一条完成下载与冻结，第二条仅访问本地原件。已有冻结记录的缓存可直接运行第二条。首次揭盲已经结束，之后运行属于复现。

```powershell
backend/.venv/Scripts/python.exe backend/scripts/benchmarks/fourier_plane/benchmark.py freeze
backend/.venv/Scripts/python.exe backend/scripts/benchmarks/fourier_plane/benchmark.py score --offline
```

可另外运行 `backend/.venv/Scripts/python.exe backend/scripts/benchmarks/fourier_plane/plot.py`（需 Matplotlib），在缓存生成 `camera-comparison.png`。图中从左到右为训练、留出以及两者之差，上排预测、下排实测，使用相同色标。

要从 BeamWeft 的实际研究接口复算，可在上述两步后运行下列命令。它会新建隔离工程，通过正式接口上传原件、运行两种设置、下载原生 NPZ 并重新计分。另一次计算直接使用实验室的振幅、波前和驱动计数，逐像元与预先制备的复场、附加相位做交叉核对。以下命令同时生成可打开的工程、完整数值回执与用产品输出绘制的图；只想核对数值时可省略所有输出参数。使用项目后端依赖，画图另需 Matplotlib。

```powershell
backend/.venv/Scripts/python.exe backend/scripts/benchmarks/fourier_plane/verify_workbench.py --package Cambridge-focal-plane.lclaw --report product.json --figure camera-comparison.png
```

工程包含三次焦面预测、两个相机原件的测量、输入与配准的冻结记录。导出后会在单独数据库重新打开工程，从归档输入重算留出设置并核对全网格指纹。两项评分使用冻结的外部评估脚本，配准系数和相机区域均来自设置 0，完整数值回执也保留了直接使用驱动计数和使用已标定弧度数组的差异。

冻结结果在 `freeze.json`，两项判定与综合标志 `joint_pass` 位于 `score.json`。浮点库和不同平台可使二进制数组哈希出现差异。每次计分都核对本次冻结的哈希。对照已发布结果时，可将两项相关系数和 RMS 改善比例的绝对容差设为 0.001。

## 用相同输入在工作台核对

冻结步骤会在缓存写出 `incident_pupil.npy`（complex64，已含实测有效幅相）及 `phase_0_rad.npy`、`phase_3_rad.npy`（float32，附加相位，单位 rad）。相位乘数均为 1。不要在复场上再次叠加实测静态波前。行号增加对应 +y，列号增加对应 +x，介质折射率取 1。采用原生 1,200 × 1,920 FFT 网格，直接计算离散复场，像元填充率与独立 sinc 包络均未校准。原生强度网格间距为 Δx=0.0025703125 mm、Δy=0.0041125 mm。

| 设置 | 模型原生峰 (x, y)，mm | 原生矩形内功率占整张计算网格的份额 |
| --- | --- | ---: |
| 0，训练输入 | (−0.77109375, +0.49350000) | 0.90902170 |
| 3，留出输入 | (−0.67085156, +0.37835000) | 0.88336421 |

此处矩形为原生数组行 [595,822)、列 [650,915)。这些数值用于核对同一输入、网格与实现；对相机的实测误差使用上文独立冻结的相机坐标和判据。
