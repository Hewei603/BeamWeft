# BeamWeft 1.9 使用指南

本指南适用于 BeamWeft 1.9.0。版本变更见[更新记录](../CHANGELOG.md)，Windows 启动和工程文件操作见[本机使用说明](WINDOWS_TRIAL.md)。

## 当前推荐工作流

1. 在首页选择 **新建工程**，输入名称后进入工作台。要找回之前的实验，可在 **实验工程** 中搜索名称或备注。工程卡上的文件数和计算数来自已保存的记录。从本机工程文件打开后，首页和工程目录会带你回到文件保存时选定的光路版本，包括尚未采用为正式版本的候选方案。
2. 新工程可以直接手工建模，也可以先放入测量文件。空白工程保留空的元件表，入射半径留待填写。选择单程或平凹腔示例后，工作台才会带入该示例的光路和参数。使用 Agent 时，从首页 **Agent 配置** 或工程对话右上角的 **模型设置** 选择模型。Codex exec 与 OpenAI 接口可在模型旁选择 **推理强度**。保存后供后续任务使用。有配置记录的任务可在 **任务结果** 中核对 **本轮模型**。从对话设置返回可接着编辑当前草稿。首页的 **Agent 工作台** 入口会定位到同一工程的对话框，**返回光路** 会保留尚未发送的文字。[接入方式和适用档位](CODEX_EXEC.md)
3. Agent 搭好并保存光路后，可以直接在上方画布选元件、改参数、查看复算结果。没有主光路且只有一份已存方案时，打开工程会直接进入这份方案；有多个方案时，在画布上方选一个。手动保存后，重新打开工程能找到续作。要复核 Agent 当时的设计，从那条历史答复打开原版。有未保存的修改时，可以在新标签页查看另一版。单独做材料计算或数据分析时，从 **任务结果** 查看科学记录。
4. 在光路图上点元件名称可以编辑参数。距离很近或共面的元件共用一个标签，点开后按顺序选择，图上保留实际位置。窄屏可以边看光束边改属性。参数改动后，标为“上一次计算”的淡线仅供对照，当前数值随复算完成更新。在 **当前工程** 可以核对参数来源与约束、查看束腰及截面光斑、切换半径／直径和单位，并导出 CSV、SVG 或 PNG。
5. 在 **分析记录** 切换传播、腔模和参数扫描，核对所用模型、场景及来源；在 **证据与约束** 检查用户信息、附件、假设与待补数据，在 **执行记录** 复核真实调用。历史专用工具收在高级记录中，不作为任务入口。
6. 工程编辑器可增删元件、修改自由参数、保存新版本和二维扫描。已有硬件参数有锁定约束，历史工程继续保留。报告和概览优先使用最新工程；原始参数保留为来源记录。
7. 当结果为“部分完成”或“需要补充”时，可以先使用有数值依据的部分，并按提示补数据。腔模计算回答几何稳定性；判断指定模式的小信号增长，还要提供增益与损耗。当前的四能级和径向温升模型各有适用范围，预测饱和输出功率仍需额外的物理模型。

通用工具支持单程、驻波腔和共面环形腔、T/S像散、薄／厚透镜、GRIN、ABCD矩阵、实测焦散和功率曲线拟合。当前运行Python/NumPy内核，尚未接入Rezonator C++。详见 [工具能力与边界](WORKBENCH.md) 和 [历史真实案例验收](releases/2.0.0/README.md)。

## 围绕同一个实验工程工作

在光路图上轻点元件符号或名称可以查看它的参数和光斑。拖动可调元件才会改变位置，也可以直接在属性里输入坐标。窄屏上的属性从图下方打开。浏览元件库、采集自己的组件模型或比较工程版本时，光路图仍可见。

对准两束光时，先看图上方的 **纵轴**。选 **工程光轴 · 切向 T** 或 **工程光轴 · 弧矢 S**，能看到两束光在同一方向上各经过哪里。粗线是束心，旁边的细线给出已知半径。想单独比较聚焦程度时，可切换到 **束宽 · 相对各自束心**。查看远处的元件或观察面时，可以直接从属性列表定位，画布会保留当前放大倍数。

在实验屏或样品处登记观察面，展开 **查看观察面横截面**，可以按相同比例读出两束光的上下、左右偏移。理想高斯模型的椭圆表示 1/e² 强度边界，二阶矩或等效宽度用线段表示。如果只知道一个方向的束心，界面会保留该方向的偏移值，指出另一个方向还缺什么。点 **引用此观察面问 Agent**，即使工程里有重名的屏幕，对话仍能关联到选中的观察面和支路。[双光束对准示例及操作记录](../output/acceptance/alignment-canvas/README.md)

要边看图边提问，点工具栏的 **Agent 对话**。要讨论一件具体器件，可在它的光斑读数旁点 **引用所选元件问 Agent**。除非已经明确引用某个已存版本，发送时会采用那一刻的画布草稿。你可以先写问题，再调整参数，最后发送。**返回光路** 会收起对话并保留未发送的文字和附件。全屏内也能展开回复全文。点 **查看本轮结果** 可转到完整的执行与结果记录。

在端口网络中，如果元件相距很远，点 **全图** 可看连接关系。在元件列表选取对象，再点 **定位所选** 可看清各端口。拖动空白处或用方向键平移视野，加减键缩放。视野和节点的图面坐标独立于连接的物理长度。

如果发问时还有无法采用的输入，点 **回到工程编辑** 会定位到需要处理的字段。元件位置可在图内修正；未应用的完整模型文本会在工程编辑器里打开。处理后再打开对话，先前的问题和附件仍然可用。

**软件更新后，怎样查出光斑为什么变了？** 在光路版本目录选中原来的工程或试算快照，打开 **求解器与复算**，点击 **用已存输入复核**。这会用当前安装的求解器再算一遍原来的光路。即使画布有尚未保存的改动，复核仍取所选版本的输入。也可以请 Agent 复核同一份存档。

先看保存时和复算时的输出。若有差异，表格列出字段和两边的数值，数值按保存精度逐项比较。再看 **求解器记录** 中的应用、计算方法、外置元件模型及运行环境。两个插件可以标有同一版本号却包含不同实现，表中的指纹能把这种变化显示出来。如果还改过光路，可以另行对照两个工程版本的输入。几何和软件都变了时，先用当前软件复算旧几何，再比较新、旧几何在同一环境下的结果。

旧工程可能没有留下求解器记录，仍可核对它保存的数值。若当前软件读取旧格式时补入了默认值，展开 **本次如何解释旧输入** 可以看到原字段和这次采用的值。独立计算若提供 **用已存输入在当前环境计算**，生成的结果可与历史记录分别打开；同一计算被沿用时界面会注明。数值复现以后，判断模型是否符合实物仍要看测量条件与实验数据。

在两镜端泵设计中，工作台默认采用已有依据的输入。有了激光波长、腔镜面形、介质折射率和安装尺寸，可先看冷腔结果。泵浦资料齐全时，即使腔镜尚未选定，也可按泵浦波长、源端束腰和发散角、透镜焦距及固定镜位，计算光束在指定介质中的传播。标称芯径可以用来估计几何芯像，预测实际光斑还需要源端光束资料。

若想比较允许采购或改变布局的方案，可以让 Agent 在给定约束下探索，也可在设计表单选择条件探索。选中候选或扫描点后，可以打开对应的冷腔、泵浦光路，或在同一块晶体上查看两者。泵浦源端有完整的二阶矩测量时，探索按实测束腰和发散半角传播。用标称纤芯和 NA 建立的候选会保留源填充假设，光斑标为等效半径。只有元件位置时也可以先编辑布局，待补全输入后再看传播结果。工程的“方案假设与待核验项”可以返回原记录与所选行。

打开联合光路后，画布以 M1 的腔内反射面为零点，各束光使用自身波长下的晶体折射率。将观察面移到实验关注的位置，可以直接比较各束光在该处的半径、宽度定义和晶体内深度。主路的空心菱形和支路的实心圆对应同一截面。浅色填充标出 T 向近轴包络，强度分布需要相应的场模型或实测资料。单独打开泵浦光路时，画布零点在光源处，工程记录中保留该源面相对 M1 的位置。[泵浦与冷腔的截面对照测试](../backend/tests/test_saved_design_geometry.py)

在画布上可以用 **撤销**、**重做** 比较修改前后的光路。单次拖动或在同一参数框里连续键入算一步。按住元件时按 Esc 会回到拖动前的位置。在画布上用 Ctrl+Z 撤销，Ctrl+Shift+Z 或 Ctrl+Y 重做，Mac 使用 ⌘Z 和 ⇧⌘Z。焦点在文本框内时，快捷键编辑该框中的文字。

在当前编辑会话中，保存工程后仍可撤回上一步。此时画布显示待保存的修改，磁盘和同事看到的正式版本仍然有效。切去查看实验资料再回来，两侧的操作记录都在。重新加载页面时，未保存的草稿会整体恢复，可一步回到它的来源版本。打开其他历史版本或独立方案时，会从所选版本开始编辑。与同事的版本合并后，第一次撤销只撤回本次合入的本地修改。

改过光路以后，可以在画布底部展开 **使用这一来源的计算**，选中旧版。工作台在本案例的独立计算记录中查找谁用过旧版，先显示链末端。展开的记录会列出直接引用的量、数值、条件和上游计算。即使功率仍是 2 W，计算它的另一项输入也可能已经改变。点 **预览复算** 可查看要重做的步骤，补上参考面或工况说明，再保存新结果。只查看或预览会保留原有计算。

反过来，从 **分析记录** 打开一项结果，**工程来源** 会列出它和上游步骤实际引用的工程版本。两份方案共同参与时会分别列出。若画布正显示另一份保存版本，可在要替换的来源旁点 **预览换用**。版本不同只说明计算时使用了另外的输入快照，具体数值是否改变可以通过复算检验。纯原件分析或手填计算可以完全独立于画布。

从资料入手时，在 **实验资料 → 查看原件信息** 中展开同一入口，可看到采用此文件的计算及其衍生结果。在 **分析记录** 打开一条中间结果，也可以顺着它继续向下查。检索依据是计算保存的输入引用。手抄的数值、自由文本报告及单独保存的工程参数扫描有各自的历史记录。

在原件预览中展开 **核对原件指纹**，可以核对当前读到的字节与归档时的 SHA-256。遇到原件丢失或指纹不一致，点 **从备份恢复原件** 选择副本。内容一致即可恢复，备份文件可以改过名字，旧计算仍引用原编号。重新采集的数据应独立上传，同名也可以。没有归档指纹的旧文件只显示本次读取的指纹。

一次上传多份资料时，离开工程再回来仍能重试未确认的文件。刷新标签页后，重新选择内容相同的文件即可按原目录归档。如果在首次读完文件指纹前刷新，请放弃该项，再独立上传。保存工程文件前会提示未确认清单；如果服务器已经收到了文件，重新打开工程时会按上传回执核对。已经被计算结果或 Agent 任务引用的原件会保留，删除时可以看到使用它的记录。

在一条已存计算下展开 **参数搜索与方案比较**。选择要变化的数值，填写离散取值或等距范围。两个位置须一起移动时，把两个参数放进同一组，逐项填写成对的数值。可独立调节的量各占一组，工作台会计算全部组合。

光路的候选参数由元件模型和工程中的绑定关系决定。比如一片按焦距建模的薄透镜可扫描焦距，目录编号只用于追溯器件。实测标定需要更正时，在来源工程中保存新版本后复算。扫描波长时还要核对介质资料，手工填写的单一折射率对应固定折射率假设。

用一种或多种已有的数值结果评价方案。每项可选择越大越好、越小越好，或只给可接受范围。实验理由和暂定限值可随搜索保存。多个目标冲突时，**优选**保留本次采样中所有未被其他可行候选超越的方案。展开 **逐项对照两个候选** 可以查看两者在各个指标上的数值、单位和差值。点击散点或表内的计算编号，可查看对应候选的完整输入。

如果改变的是实验目标，在已存比较中修改评价条件，再点 **保存新评价**。工作台会沿用原有候选，即使接手工程的电脑没有原求解器，也能使用计算中已保存的标量。只设限值时，结果显示哪些候选符合约束。有些候选可能缺少新增指标，例如只有部分计算记录包含指定观察面的读数，表中会给出原因。新评价保留与原比较的链接，也可以点 **与 Agent 讨论这次比较**，把当前这份记录交给 Agent。需要改变光路或采样范围时，在 **比较方式** 中选择 **改变取值，重新计算候选**。

搜索使用基线的求解器版本。每次可比较最多 128 个组合。修改关联光路时会保存独立的试算版本，并保留正式工程；已绑定的实验读数继续引用原件。未满足输入要求的候选会列出字段和原因，超出用户约束的候选保留实算数值。

**从候选走到实验台。** 给关注的物理量设好验收限值，在已存比较中展开 **查看装调余量**。选择计划搭建的设定和想调整的参数。沿参数的实际取值，可以找到两侧最后一个达标的采样点，再打开紧邻的超限点或缺证点，核对当时的工况和计算。若还有其他可变参数，可以固定在名义设定，也可以要求其余已采样组合全部达标。例如，手头镜片的焦距已经测定时可以固定焦距；计划兼容几种可换镜片时，可以切换为全部已采样工况。两个达标点之间仍可能有未采到的失效区。

对于固定工况下的单个连续可调参数，若相邻两点已经分别达标和超限，可选 **缩小边界区间**，用该参数的原单位填写所需精度。工作台逐次核对中点，保留两端的原计算、新增的候选、复用记录和来源光路。遇到中点缺证时，会说明停在哪个取值和原因。每次最多检查 16 个中点。打开旧工程时，即使本机没有原插件，仍然可以阅读已经保存的采样余量。工程能支持的定位精度，还需用实物的位移读数、重复性或相关标定核验。[装调示例与复现记录](../output/acceptance/sampled-tolerances/README.md)

**决定上台后能调什么。** 在已存候选比较中展开 **比较固定与按工况调节**。把搭建时已选定的量设为设计参数，把每次操作前能辨认的条件与无法辨认的条件分别标出，再选可调量。若焦距已知，调节策略可以为两种镜片分别选探测面；若焦距未知，两种镜片必须共用同一设定。工作台先检查哪些设定能通过全部已采样工况。

有到货计数、实验日志或明确假设时，展开 **按工况出现频率评价**，填写各组联合条件的相对权重与依据，也可关联工程原件。点击 **应用工况权重** 查看达标占比，再点 **保存本次工况评价**，让同事可以从已存搜索打开同一判断。遇到证据缺失时，下界只计已确认达标的工况，上界包含仍可能达标的工况。两个界限有时需要不同的设定，点开各自的候选即可核对。工程中的 Agent 也能从原件读取频次、保存评价。[两个可重开的实验工程与验收记录](../output/acceptance/weighted-adjustment/README.md)

从 **空白工程** 开始，可以在画布上逐件添加光学元件，也可以直接打开 **我的元件与组件模型**。切换 **光路表示** 可在同一工程中编辑顺序光路和端口连接图。在端口的入射设置里，可以引用上游功率预算，再以某个工程参考面上的横向复光场作为入射分布。

要在另一个案例中复用一套器件，先保存来源工程版本，在模型库选择 **将光路存入库**。在顺序光路上选择连续范围，在端口图上勾选所需元件。库会保存选中器件之间的连接长度、损耗、相位和横向配准。插入后，每份组件都有独立身份，外部端口可接到新实验的光源与探测位置。可以在尚未保存的草稿中连续插入和撤销。版本记录保留元件模型来源及建模波长。

同一件实物包含传播光路和端口器件时，在 **组件范围** 同时选中两者。勾选需要随件移动的观察面。固定在实验台上的坐标只有在选中时才会转换为所选元件内的深度。需要保留透过率等标定值时，勾选逐件传输参数。库中 **查看组件内的取光位置** 会分别列出每个端口的功率和光场来源，两者可以在不同截面。将组件插入新工程后，使用接收工程的照明条件计算。端口图用虚线连接这些来源，点选功率或光场即可回到对应元件或观察面。原来引用整条主光路末端的内部光场会绑定到复制元件的出射面，之后再接其他元件也能保留配准。

### 在光路图上调参并核对实测

**当前工程 → 光路中的对象** 跟随画布上的编辑。首次保存前也可以选中元件向 Agent 提问。对话会在发送时记录它使用的光路和元件，因此你可以保留主工程，再比较 Agent 对草稿的计算。顺序元件和端口元件可在同一列查找。点击端口行会打开该端口的属性，显示它连接的元件、指定的入射光源或匹配端接。

在图上点选元件，或从图旁的元件列表选择它。直接在 **所选元件参数** 中编辑焦距、曲率、介质参数或自定义矩阵。主光路和入射支路使用相同的元件编辑方式。展开图下的 **主光束参数** 可调波长和入射条件。编辑期间保留全屏，右侧读数对应所选元件，图下的观察面可选在另一个位置。等待新计算时，淡线保留上次算出的包络，当前数值等回执到达后更新。

在已保存工程的观察面下登记相机原件、采集条件和仪器宽度口径。只要光路经过该面、位置能唯一确定，就可以先记读数。画布下方的“实测”标出采集时的轴向位置，点击标记可查看原始单位、光束、工况和文件位置。同一位置的多次采集会列在一起。有可比半径时，主图同时显示实测点，圆形代表 T，方形代表 S。仪器给出的半高全宽按 FWHM 保留。调参时，采集版本的坐标和基线保持固定，可在图例中隐藏。保存新版本后，使用“用实验读数检验这版光路”选择原有读数，说明两版的定位依据和实验工况，即可取得同口径的预测和残差。

在主光路画布、工程元件列表和入射支路中，选同名内置预设会得到相同的物理参数。画布插入会占用所选空气段，列表追加会延长光路，驻波腔会把新元件放在末镜或其组合之前。每次放置都是独立实例，可以给它命名并按实物资料修改。Agent 可以通过元件库查询同一份示例参数，也可以读取某个工程版本中已经采用的值。

打开一个尚无扫描记录的谐振腔时，二维稳定图从该工程选择两个不同的参数，优先选择未锁定且有数值的参数。有已保存的扫描时，打开该版本会恢复当时的坐标轴与扫描范围。

### 手工运行一次计算，再由同事或 Agent 继续

在案例的 **实验工作台 → 分析记录 → 运行独立计算** 选择方法。刚创建的空白案例也能在这里做功率拟合或相位匹配。有完整光路模型时，可以直接输入模型做近轴传播。点击 **运行并保存结果** 后，本次输入、适用说明、计算版本和数值会一起进入案例。用 **用这些输入再算** 改动一个条件，或用 **引用这次计算问 Agent** 让助手接着分析。导出案例后，同事可以打开当时的结果和输入，界面会说明复算所需的扩展版本。

**例：已知泵浦，指定的信号模式绕一圈会增长吗？**

1. 已有近轴工程时，选择 **沿增益段计算泵浦与信号重叠**，引用保存的工程版本，指定信号光束。工作台分别列出与该束相通的泵浦支路和介质段，给出沿段积分的有效重叠面积或缺少的条件。
2. 如果材料可用稳态四能级近似，选择 **稳态四能级小信号模增益**，引用相应段的面积，填写该工况的发射截面、寿命、量子产额和适用泵浦范围。如果手边已有弱探针扫描，可直接从原文件选取吸收泵浦功率列与探针功率比列，运行 **实测弱探针增益曲线**。这条路可以从空白案例开始。
3. 在 **连续波小信号往返平衡** 中引用所选增益曲线。填写一圈的等效通过次数，以及尚未计入曲线的无源功率保留比例。可以填入或引用某段的吸收泵浦功率作运行点。图中零线表示一圈后功率相等，正值表示增长，负值表示衰减。扫描若出现平台或回落，可以有整段平衡或多个平衡点。

注意输入标的是**样品实际吸收的瓦数**。台面功率计在入射端读到的瓦数，需要先核算途中损耗与样品吸收。来源波长与目标冲突时，工作台会说明两者的数值；若跨支路或样品借用数据，要留下依据。温度、偏振和测量口径仍须从参数来源核实。上述结果描述微弱信号在给定条件下的变化，实际稳态输出还取决于饱和、竞争等效应。

### 从非相干光源算到接收面

在 **分析记录 → 运行独立计算** 选择来源。手工计算和 Agent 都能在同一工程里接续这些记录。

- 只有发射面尺寸与数值孔径时，选择 **扩展光源的相空间边界与采样**。几何范围足以判定某些光阑必然全通或全挡；部分遮挡时，未知填充可能只允许给出 0–100% 的范围。要比较某种填充情景，可登记位置和方向分布的依据。输入已配准的非负近场强度图时，也要另行说明角度分布及其与位置的关系。
- 已有逐条光线的 CSV、表格或文本时，选择 **从逐行位置、方向与通量建立光线束**。选取同一条记录的横向位置、方向和功率列，核对原件单位。方向可以是两个斜率或朝前单位向量的三个分量。不同起始面可在已知均匀介质中投影到工程入口。逐条辐射功率可以提供总瓦数，等权或相对权重只确定份额。
- 在单程工程的画布选择 **加权光线传播**，引用保存的来源，说明入射面的坐标和介质，随后调节镜间距、开口或取样面。可以同时指定接收器的位置开口与角度接受范围。接收份额相对于最初发射功率。引用同一工况的发射功率后可读出瓦数。探测视场只限定图像和视场积分，视场外幸存的光线仍能传给下一段。

这是带权近轴几何传播。它能回答孔径遮挡、几何传输与集光问题。衍射、相干模式匹配、材料吸收与激光输出各需相应模型。收光面的二维图显示每格积分的权重。观察局部暗区时，应结合采样数、分箱大小与原始测量判断。

### 从光路上的一个量继续计算

入瞳场已经测得时，可以在 **分析记录 → 运行独立计算 → 理想透镜的后焦面衍射** 直接使用二维原件。提供复振幅数组，或者提供同一孔面、同一采样位置的振幅与相位。相机强度要按强度口径输入。只有强度时，相位仍是未知量；已有平坦波前依据时，可明确采用该假设。相位板或调制器的附加相位可以分别绑定自己的原件和读数到弧度的标定。填写真空波长、焦距、横纵向像元间距与行列在实验坐标中的方向后，即可计算二维焦面光强。[物理原理](https://interactivetextbooks.tudelft.nl/interactive-optics/content/Chap6_Diffraction/DiffractiveOptics_2022_01Clean.html)

峰位与积分使用完整傅里叶网格。在图上框选想看的区域，工作台会按原生采样取回细节，并沿用全图色阶。把光标停在亮纹上可读出坐标与强度，点 **返回全图** 可恢复视野。结果可以导出带毫米坐标边界、信号单位和原件摘要的 NPZ。每格数值是该单元的积分，除以格面积才得到图中的密度。导出和 Agent 复核会用当前安装的同版本求解器从归档输入重算，并核对原计算的全网格指纹。需要在没有该方法的环境中继续分析时，可一并保存 NPZ。相机采集的二维实数 NPY 也可以直接交给 **图像强度与二阶矩**，按实验记录设置暗场、像元尺度和选区。[公开实验、对照图及复算方法](../backend/scripts/benchmarks/fourier_plane/README.md)

相机前的光路已经量好，后面的元件资料还在等，也可以先预测相机上的光强。在光路图中选中相机所在的观察面，展开 **随光路更新的计算**，选择 **相干光场传播**。面板会写出本次计算的起点和终点。主光路、独立入射支路可以使用各自的光源和波长。光斑图采用相对入射功率密度，视场内的积分功率与孔径通过的总功率分别列出。

保存结果后，从 **分析记录** 可以查回计算用的工程版本、观察面和元件。打开 **参数搜索与方案比较**，可改变已确定的孔径或可调元件。每个候选保留整份工程，尚未测定的下游材料也随工程保留。观察面若固定在实验台上，可在工程内直接编辑它的绝对坐标，再用同一观察面复算。对于腔内本征模，仍要补齐决定往返传播的元件。可以打开这份含实际 Agent 答复和二维光强图的 [780 nm 相机示例工程](../output/acceptance/scoped-layout/agent-camera.lclaw)。

### 拿相机原件检验已保存的预测

如果实验问题是“光斑落在哪里”，有一个保存过的观察面和一张相机原图就可以开始。在 **实验资料** 里用 **图像强度与二阶矩** 登记背景、响应及物方像元节距。回到光路图，选中观察面和光束，打开 **对照实测束心**，选这次测量和两套坐标之间的标定。表中 T 是切向、S 是弧矢方向，差值为配准后实测减工程预测。正负号给出偏移方向。如果模型只知道一轴，仍可查看该轴的差值。

相机原图的第一个像元中心是列 0、行 0，裁剪会保留这个原点。若安装位置和转角未知，可以把同一物方面上的标记点整理为四列坐标，在 **分析记录 → 用标记点配准两个横向坐标系** 中引用原件。选定列的单位，预留几个不同位置的点，再设置实验允许的最大位置差。软件拟合平移、转角和镜像。手性不明时，配合分布在平面内的非共线标记能排除镜像歧义。超出限值的拟合保留逐点诊断。通过的标定可同时引用到束心对照与两幅光强图比较。

标定最好来自机械基准或独立标记。用过去几帧光斑的平均位置定义原点，可以回答后续光斑相对这个原点漂移了多少。若要检验光斑离机械轴有多远，还需把该原点与机械基准实测联系起来。比较前也要核对成像倍率、波长和观测窗口。下面的公开氦氖激光原图可用来练习这一区分。[实测工程、逐轴差值与可复算步骤](../output/acceptance/registered-centers/README.md)

如果要进一步判断光斑的**分布形状**，需要两幅有物理坐标的强度图。操作如下。

1. 在测量前保存目标平面的预测。实验后将相机原件放进 **实验资料**，选择 **用整份原件计算**，打开 **图像强度与二阶矩**。可选取原始帧号、选区、同工况暗场或均匀背景。登记物方像元节距和读数响应，已知线性与暂按线性分析可分别记录。二维比较要求行、列两个方向都有物方尺度。
2. 打开 **横向光强图配准比较**，分别引用已存的预测和测量。两次独立采集也可以互相比较。说明两者的测量面、坐标原点、轴向和工况。平移栏要填观测原点在参考图中的位置，单位为 mm。镜像和转角应来自传感器与光路的安装关系。若目标是检测指向漂移，用原来登记的位置就能保留真实偏差。
3. 图中可在同一位置查看两份分布和差值。两图共用强度色标，残差是观测减参考。红色表示观测偏高，蓝色表示偏低，灰格表示缺少能比较的完整像元。质心位移说明光斑往哪边走，L¹ 汇总共有区域内两份归一化分布的差异。要比较绝对信号，另填独立标定系数及其依据。

这些步骤也可以用自然语言交给 Agent。旧记录若只存了出射复场，可以从该场在原参考面重新取样。示例工程保留了两张公开氦氖激光原片、预测模型和比较结论，可从计算记录一路打开原件。[实测对照和可重开的工程](../output/acceptance/intensity-comparison/README.md)

在光路图选中元件，可以从检查器中的物理量查找后续方法。在 **分析记录** 打开一项已保存计算，也可以从它公开的物理量继续。选定输出后，目录会按物理含义、单位和数值形式筛选已安装的方法。例如，同一个波长可以用作和频计算中任意一束光的输入。这时先选它对应哪一束，再填写另一束的波长。光场状态还需要说明上下游参考面和横轴如何对应。

也可以在 **运行独立计算** 中先挑方法，再选择各个输入来自工程、已有结果、原件还是手填值。两条路径都记录实际使用的工程版本或计算编号及输出字段。Agent 也能用这份引用寻找后续方法。类型匹配只说明软件能传递这个量，使用时仍要核对工况与模型的适用范围。

在晶体或窗口的观察面选中束名，使用 **介质段传播与界面折射** 可以从介质内部接着走。即使截面设在段末，其状态也取该段内侧。填写当前介质中还要走的实际距离；穿过界面时再填写透射侧折射率。曲率半径留空表示垂轴平面，球面曲率中心在下游取正。结果中的束心指向和波前曲率都是当地介质内的物理量。已有空气参考面也可直接连接。需要从实测宽度开始时，在 **实测光束焦散拟合** 登记连续介质内的位置、横轴和宽度口径，再从结果选取 **介质内逐轴近轴光束状态**。仅测到一个横轴时，另一轴及束心指向仍显示未知。

有些测量足以回答一部分问题。给出同一均匀传播段、同一横向轴上的位置与半径，就可以拟合束腰和几何发散。求 M² 还要知道真空波长及该波长下的折射率。介质未知时留空，按空气近似时填 1。请注明宽度口径，在接收半径的输入栏里应使用 D4σ 全直径的一半。原件表格分析会按选定的仪器口径换算。选取已存结果里的 **实测焦散几何模型**，即可在同一参考系里预测其他位置的光斑，区间外的预测会标注外推。拟合时使用的测点与后来用于验证的测点应分开保存。[光束传播理论与宽度口径](https://laserbeamsize.readthedocs.io/en/latest/12-M2-Theory.html)

如果测量已在同一份文件里，可以在拟合前指定几个位置，专门检查预测。填写表格时可选采集标识列，例如相机帧号。工作台会把相同位置的重复读数，以及同一次采集关联的其他位置，放在同一组。结果列出实际用来拟合的范围和每个留出位置的实测值、预测值、差值及原件记录。半径均方根误差按位置等权汇总，多拍某一个位置不会增大它的权重。在 **实测光束焦散拟合** 中输入数组或引用原件列，也可以做同样的检验。

这项误差回答的是同一批实验里没参与拟合的位置能预测到什么程度。要检验下一次实验，先按目标位置保存预测，再归档新测量并和该预测对照。满量程像素、轴向定位或像元标定误差需要单独核查。可以用公开的氦氖激光相机扫描复现一次完整对照。[实测基准、原件来源与复算方法](../backend/scripts/benchmarks/measured_caustic/README.md)

原表已有样本号或曝光文件名时，可以直接为文本输入选择那一列。若同一张表的某行缺少编号或读数，可修正来源，也可选择整行排除，保存的结果里能查到跳过的记录号。Excel 中带前导零的编号请用文本单元格保存。例如 `0017` 若仅靠数字格式显示，单元格实际存储的是 `17`。已有的手填标签仍按输入顺序与读数对应。

同一位置拍了几次，可以保留每次的原始宽度。打开分析结果里的 **查看各位置的重复读数**，能看到该处平均半径和样本标准差。即使今天只测了一个位置，也能保存并重开这份记录。测点足以拟合传播曲线后，分别查看各位置的平均半径与曲线有多接近，以及单次拍摄通常偏离多少。后续用拟合预测其他位置或建立工程入射束时，同位置波动明显的提示会随结果保留。

例如，侧面冷却圆柱的径向温升可以引用某段的体吸收和长度。热转化比例、受热分布、材料热导率与冷却边界需要各自的依据。对端面绝热、轴对称且热导率为常数的圆柱，工具用每个半径内包围的热功率积分出相对侧壁的轴向平均温差。未知侧壁换热系数时，仍可查看径向温差曲线；测得系数后才能估计相对热沉的温升。均匀满截面热源的解析校核值为 ΔT = P热/(4πkL)。[Koechner 与 Bass，第 7 章](https://api.creol.ucf.edu/Publications/3601.pdf)

经过有限孔径的相干光束可能出现衍射环。需要预测下游屏面时，先在 **相干光场传播** 里保存孔面或中间面的计算，然后从结果选取 **可续算的相干光场**，接到下一段光路入口。配准时核对横向原点、T/S 两轴和前进方向。第二段可以更换视场和采样数。工作台从原始相干源重放已经求值的孔径、相位面和传播段，累计通过率始终以最初的入射功率为基准。

下游记录显示本段坐标和自光源起的累计距离。查看通过率时，也要看图内功率、双网格差异和采样提示。若手头只有相机强度图，仍可量光斑和拟合焦散。要预测孔后的衍射图样，还需提供有依据的输入波前或具备相位信息的光场模型。

若打开的是早期相干传播记录，可以在原记录下点击 **用 v2 重算原输入**。新记录会保留原工程版本、配准说明和回到旧结果的链接。孔径边界处的数值会随采样方法改变。比较两次结果时，可以在新记录查看细、粗网格间距和孔面采样位置。

### 在同一张光路图上分束和合束

新案例可以从 **建立端口光路** 开始。已有顺序工程可在光路工作台右上角把“光路表示”切换成 **端口连接图**。添加元件后，点击圆点选中一个端口。在“端口入射”指定光源，或在“连接到”选择另一个空闲端口。拖动元件只改变图面排布；选中连接后修改物理长度、折射率或附加相位，才会改变计算。

可用两个理想 50/50 分束耦合器检查自己的接线。波长设为 1000 nm，把 2 W 从第一个器件的 1 口射入。此时 3、4 口各有 1 W。将它们分别接到第二个器件的 1、2 口。在本工具的端口相位约定下，两条臂等光程时，第二个器件的 4 口得到 2 W。把任一条空气臂加长 0.0005 mm，再观察 3、4 口的读数。两路若来自独立激光器，保持“相干组”空白；已知光源锁相时才填写相同组名和各自的参考相位。

用户自定义元件可在“元件参数”里指定端口名及复数散射矩阵。顺序光路已经做过功率预算时，也可在“端口入射”里选择同一波长的工程出射功率。保存后点击端口出射读数，可以把这个版本的数值交给兼容的计算。Agent 修改的是同一张图，回到工程版本列表即可比较修改前后的连接和读数。

### 从归档原图计算光斑

整份实验原件也可以直接参与计算。在 **实验资料** 中找到文件，点 **用整份原件计算**。目录优先列出能识别文件格式的方法；“需要试读”里的方法也可以选择。如果所选文件只有一个明确的输入位置，表单会带入它。信号和暗场都符合时，可根据采集记录自行指定。对有序采集列表，可以添加、前移、后移和移除原件。结果旁会列出文件用途、序号和 SHA-256，点文件名可回看归档原件。没有搭建光路的案例也可使用这套流程。

**从相机帧测光斑。** 在 **图像强度与二阶矩** 中选择线性单通道信号原图、帧号，以及有依据的同工况暗场或均匀背景。像素尺度按所测平面填写。缺少尺度时仍可获得像素单位的质心和 4σ 直径。图像以左上像素中心为原点，沿列向右、沿行向下。图中的椭圆对应指定窗口的二阶矩。框选图中区域后用 **用图中选区重算**，工作台按显示的原图行列范围重新读取像素，并保存这次计算。两次结果都可从分析记录打开。

图中的色块可能是多个像素的均值，数值计算使用选区内全部解码像素。扣背景后的负读数参与求和。暗场失配、限幅或选区截去光束尾部都会影响宽度。相机坐标和光路的切向、弧矢方向要依据实际摆位配准。多帧 TIFF 可按指定帧计算；彩色预览截图须先有可解释的通道和线性响应。关于背景对二阶矩测量的影响，可参考公开实验资料。[激光束实验相机数据与背景分析](https://laserbeamsize.readthedocs.io/en/latest/03-Background.html)

### 从仪器表格直接计算

在 **实验资料** 打开原件，核对工作表、数据列和范围。点击 **用这个选区计算**，选择需要的方法。在每个数列输入旁选择来源、原件列号和原件单位。可以把另一份文件或已存计算用于其余输入。跨来源配对时，写下读数的对应顺序。例如两台仪器按同一触发序号导出了等长记录，需先核对两边是否漏采。记录号和数组长度本身不能确定时钟同步。

求解器从原件逐行读取。图表即使只展示部分点，选区内的有效测点也会全部参与计算。数据中出现空白或过量程时，界面会指出具体行列。也可以明确选择整行排除，同一选区的配对数列会一起排除该行。**校准** 可填写乘数、原单位下的偏移和依据，然后系统换算成求解器单位。例如原件记录直径而拟合需要半径，可填写系数 0.5 并注明宽度口径。

在分析记录的 **输入来源** 点击文件名，会回到本次选区。展开来源说明，可核对归档文件的 SHA-256、实际使用与排除的记录号、范围外的记录数。用 **用这些输入再算** 可以沿用该映射或修改条件。原件以外的假设仍可手动填写。

### 在另一台电脑上复核案例

点击 **新建工程**，给工程起名后即可在空白光路上放元件，也可以先放入实验文件。即使没有光路版本、实验目标或模型服务，仍可保存空白工程。点击工程标题旁的 **工程操作 → 编辑** 可以补写或清空目标与备注。也可以直接请 Agent 更新工程资料。

**保存工程文件**（Ctrl+S）生成可独立打开的 `.lclaw`。它包含这个工程已存的模型版本、计算及关联实验原件。画布上的有效修改会先保存为光路版本。位置框中的合法数值随文件保存，遇到无效数值或未合并的草稿时，窗口会保留输入并说明要核对的位置。在支持系统文件写入的浏览器中可以选择目标文件，其他浏览器通过下载交付。

在同一个工程窗口上传整个文件夹时，也可以直接按 Ctrl+S。工作台会等到文件收到归档回执后再保存。个别上传失败时，窗口会指出文件名，可以重试或明确选择只移交已归档部分。在「实验资料」输入目录和文件名片段即可找到原件。同名文件可以按相对路径和原件编号区分。

在使用本机启动器的工作台首页或工程目录点击 **打开工程文件…**，也可以把文件拖到 `Launch-BeamWeft.bat`。接手者首先看到发送者保存文件时正在看的光路，可以是主工程、历史版本或独立方案。从方案保存文件后，主工程仍保留原先采用的版本。接手者可以直接对眼前的光路提问，或从 **方案与版本** 切换。早期文件没有记录起始视图，初次打开会显示主工程。如果只需要单一版本的模型参数和计算数据，可以在光路详情中选择 **导出此光路版本 JSON**。

直接打开 `.lclaw` 后，工程标题下方显示它所在的文件夹与文件名，展开可核对完整位置。按 **Ctrl+S** 会写回该文件。要从当前光路分出一份工程，按 **Ctrl+Shift+S** 或点 **另存为工程文件**。选择新位置后，窗口会打开新文件，以后的保存也写到这里。如果你在等待新文件打开时已经继续编辑，界面会留下正在编辑的草稿，并给出 **打开新文件** 链接。磁盘文件被其他人改过时，保存会提示冲突。

接手者可以在另一台装有 BeamWeft 的电脑上打开文件。旧的 ZIP 仍可打开为工作副本，再通过 **保存工程文件** 存成 `.lclaw`。

搭到一半也可以保存。只放了第一面端镜的驻波腔，接手者会看到布局和待补条件。补齐两端镜与传播距离后，若各元件的近轴传输已知，即使波长待定，也可查看两轴的几何稳定性。绝对光斑尺寸还需要波长。单程系统还需入射光束条件。点击光路图上的待补项可以回到对应参数。仪器的原始读数可以先登记在已知测点上，等仿真条件齐全再比较。

例如，接手者可以从分析记录打开先前选定的示波器读数，再回到原件改选一段时间，核对峰值对应的行。也可以打开旧光路，改动透镜位置，保存新版本并比较两次结果。接收方的 Agent 使用本机模型配置。

案例包携带已保存的工程版本、原始附件、案例模块文件、案例的知识索引、工作台和设计会话及其工具记录。库存只携带工程引用的规格，在接收方登记为零件数待核对。整个实验室的共享文档、其他案例和私人会话仍在来源工作台。依赖外部资料的历史结论可读，继续使用外部资料时需要重新提供依据。旧版 ZIP 缺少的工具过程、索引和规格会在接收界面注明。只有浏览器里的未保存草稿需要先保存，才能随包交接。

已安装前后端依赖的其他桌面系统，可在 `frontend` 运行 `npm run build`，再用后端 Python 环境运行 `python backend/scripts/open_case_bundle.py "<案例包路径>"`。命令从仓库根目录执行。`--root` 可指定保存副本的目录。

### 编辑案例工程

进入案例的 **实验工作台**，直接向 Agent 提出目标、给出已有条件或补充测量。Agent 可以维护实际元件资料、建立单程／驻波／共面环形近轴模型、计算或拟合并保存结果。不同任务使用同一套对象、版本和工具，不需要先进入某种实验模块。

在 **当前工程 → 光路中的对象** 选择一件实物或传播段，查看来源、参数和未知项。**向 Agent 提问** 会携带工程版本、对象身份及库存引用，不依赖写有特定材料或腔型的续写模板。**选择库存元件** 是该对象的一项编辑操作，可以从库存选择或当场新增；元件库页面也支持手工录入，无需先制作 Excel。库存记录修改与在工程中采用某件实物分开，历史工程保存采用时的参数快照。

录入时只填写已知参数。可以上传标签照片：识别结果先作为草稿显示，点击 **采用识别草稿，填写到表单** 后再核对保存；识别不会自动入库或替换工程。照片模糊、文字遮挡、含义未明确的参数继续保留在原文和待核实说明中。手工输入也始终可用。不知道晶体的分段时，可以取消“录入晶体分段用于仿真”，先保存标签记录，补齐材料和段长后再用于计算。

- **复合晶体**：按标签顺序逐段填写材料与物理长度，作用由材料确定，支持无掺杂端帽、Nd 增益段和 Cr⁴⁺:YAG 可饱和吸收段。掺杂浓度、截面尺寸和镀膜未知可留空。替换时另选泵浦进入的一端；实物朝向未确认时，这项只是计算假设。预览会显示总长和镜间距的变化，保留原有外部空气间隙。
- **输入镜 M1**：填写腔内反射面的曲率半径 R，或明确选择平面镜。未知曲率不能按平镜计算。更换后保留位置及其他元件并复算冷腔；808 nm 透过镜片后的聚焦还取决于基底、厚度及另一面曲率，单个反射面 R 不能代表完整泵浦透射模型。
- **输出镜 M2**：曲率变化会改变腔模；只有镀膜透过率变化时，理想冷腔 ABCD 几何可能完全相同。输出功率、阈值和效率仍需增益与损耗模型及实测参数，不能因为图形相同就认为输出行为相同。未知透过率不会自动补成 5%。

在画布选中主光路或入射支路上的元件，点击 **更换库存实物**。候选列表会检查库存数量、借出数量和本工程各位置已占用的件数。选择候选后，可以在同一个观察面比较换件前后的 T/S 光斑半径，再切换到另一件。只有确认采用才会写入版本。也可以向 Agent 说明选择标准，由它使用相同的库存和试算结果比较。正在编辑独立方案时，换件会保存方案的新版本，之后可从版本目录采用到主工程。

换件时，外表面的连接会随新实物更新，固定在实验台坐标上的观察面继续使用原坐标。若旧件的内部分段与新件无法对应，界面会列出需要重新定位的观察面或端口。旧实物的损耗、净孔径以及单独标定的支路折射率仍可在原版本查阅。使用新实物时，可填写该波长和偏振下的折射率；确认与同波长主路采用相同介质模型时，可对该段选择 **此段沿用主路 n**。

保存后可在同一个对话中继续要求扫描、比较、解释结果或指导补测。计算记录保存实际模型及参数；与已保存工程相符的扫描关联其版本，探索模型单独标注，不冒充已安装光路。带 Cr⁴⁺:YAG 的晶体可计算条件冷腔模场，但当前工具未实现吸收漂白与被动调 Q 动力学，不输出脉宽、重复频率、单脉冲能量或最大功率预测。

### 在光路图上移动一件由多个元素表示的实物

一支镜筒可以由正透镜、内部空气段和负透镜三个元素组成。在图上选第一个元素，展开「定义实物组合」，选择末元素，填写实物名称。再选其中任一成员，图中的括线会标出整件实物。两侧有可调整的自由空间时，拖动或输入轴向位置会同时调整外部间距，保留镜筒内部尺寸。图上的光斑是当前所选参考面的读数，比较固定探测器时请选择固定观察面。入射支路也可以这样组织。试好位置后保存工程版本，或引用草稿交给 Agent 继续试算。

两块紧贴的同型号器件可以直接作为两件独立对象，共用一个库存条目。更换其中一块时先看预览中的实物名称和分段。旧格式工程优先使用当时保存的分段清单。只有邻接关系可用时，图中的实物详情会标注旧格式推定依据。可根据实验记录解除组合、重新划定边界并存为新版本。

### 两版光路都说得通，相机应该放在哪里

在当前工程的观察面区域比较两版光路，输入实验台上实际可放相机的位置，选择与仪器一致的方向和宽度定义。例如相机导出的是半高全宽，就选择 FWHM。也可以直接把相同条件告诉 Agent。计算会保存光路版本、坐标依据、仪器口径和各测点的预测。

如果标定记录给出了宽度的绝对误差上限，以及沿光轴的位置误差上限，可以一并填写数值和依据。软件会求出相机在允许位置上可能读到的宽度，优先指出两版读数范围分得最开的测点。如果范围相交，这次测量仍有可能无法区分两版。标准差和重复测量的离散程度需要另作统计解释。没有定位界限时，结果只针对标称位置。

拿到数据后，在同一区域选择已登记的光斑和待检验版本。选择共同台架零点时，定位范围可以跨过连续、同折射率的传播段。选择元件内深度时，范围受该元件边界限制。如果范围跨过透镜等光学界面，结果会指出需要核实的位置。同一张图的 T、S 两个宽度必须在同一实际位置同时相符，结果会列出这样的偏移范围。换了一种实验工况的读数可以用来查看预测变化，检验该工况还需要对应的实测数据。

## v3.3：围绕任务选择工具

新建工程只需名称。进入工作台后，可直接用对话框请 Agent 设计光路、复核已有方案、匹配元件、分析实测数据或排查现象。

运行途中关闭了服务，重开工程后可到 **任务结果** 查看已保存的工具回执。点开一条记录，可以核对它做了什么、保存了哪些数据，或因为什么失败。如果模型已提交完整结论，页面会注明其来源。对于没有记录执行进程的旧任务，页面会显示运行状态待核实；可以刷新状态或明确结束该任务，再从已留存的证据继续。

Agent 会读取已有信息、选择工具、查看工具结果，再决定下一步。它能组合多种工具，也能在工具报错时改正输入。缺参时会解释这个参数影响什么、怎样测量或查到，以及回复的单位与格式。直接在同一输入框补充，便可继续推进。无法完成的部分会保留为部分结果或明确的能力边界，不会自动包装为“完成”。

- **任务结果**：结论、事实来源、假设、需要补充的信息、后续建议和实际计算图。
- **工具过程**：每一步的目的、真实输入输出、错误和耗时；可下载完整 JSON 记录。
- **已存光路设计**：保留已有平凹腔设计版本与 v3.2 精细分析台。它是可调用的专用能力。
- **停止 / 继续**：停止后保存已经执行的结果；正在执行的单次调用需要先结束。回复或点击继续便能复用此前记录。

当前一般光学工具支持近轴单程、驻波和共面环形系统的 T/S 计算及参数扫描。运行内核是 Python / NumPy ABCD，尚未连接 Rezonator C++ 程序；三维热场、应力、寿命、激光输出功率全局优化不在其计算范围内。参见 [任务工作区能力与架构](WORKBENCH.md)。

下面的 v3.1 / v3.2 章节记录保留的专用光路设计能力；新任务统一从 Agent 工作区提出，旧设计图表在“已存光路设计”中查看。

## v3.1：从目标、已有元件与库存求解光路

1. 首页配置 Agent。当前可填 `gpt-6.1-sol`，使用已配置的 OpenAI API Key；读图需要所选模型支持图片。
2. 在 **新建工程** 中输入名称，进入工作台后再补充实验目标和器件资料。
3. 直接按案例标题 / 描述开始设计，也可补充目标、已有元件或上传标签。展开**已有元件 / 固定位置 / 设计约束**绑定库存、锁定已经安装的主面坐标、M1 间隙或输出镜曲率。留空的设计变量交给求解器，缺失器件由库存或采购方案补齐。
4. 右侧首先给出 M1 到晶体前端面、晶体后端面到 M2 的距离，再列出候选、光学分析台、所有元件坐标和补齐清单。在分析台输入 M2 间隙或点击稳定性曲线可直接重算；点击**将此间隙用于新设计**生成独立的新版本。
5. 在同一个输入框补充或纠正参数，例如“准直镜实测焦距为 100 mm”。每次更新保留旧版本。点击问题卡可定位输入；计算失败可恢复上次输入，已保存的版本不受影响。
6. 导出坐标 CSV、腔镜选型 CSV、**Rezonator 冷腔 .rez**，或通过“保存工程文件”保存整个 BeamWeft 工程。.rez 使用全部晶体物理长度和折射率，导出驻波冷腔，不含泵浦和热透镜场景。库存是计算当时的快照，借还、导入后重新计算可刷新。

### v3.2：精确查看仿真结果

- 点击**展开分析台**获得完整绘图区。可查看束宽、对称包络、波前曲率 1/R、波前半径 R、M2 稳定性扫描；图面支持框选缩放、平移、图例隐藏和双击复位。
- **晶体 / 掺杂段 / 束腰 ±2 mm**提供局部视野，也能输入任意 z 范围。纵轴可切换 μm / mm、半径 / 直径；均以 1/e² 强度定义。泵浦束腰局部视野优先定位晶体内焦点。
- **精确游标**允许输入任意 z，直接由分段 ABCD 传播求出 w、R、q 和 n，不对绘图点插值。界面 / 薄透镜处取出射侧，光路终点取内侧；关键截面表同时保留界面两侧数据。
- 绘图密度可选 300 / 900 / 2400 点，并自动加入介质边界、解析束腰及其附近的加密点，避免窄泵浦束腰被均匀采样漏掉。小数位表示计算精度，不等于实物测量精度。
- 改 M2 间隙、热透镜焦距只做即时预览，不调用 LLM，不改动已保存坐标；需采用新间隙时生成新版本。热腔图同时显示同间隙的冷腔参考。无稳定本征模时明确显示无解，不补画虚构光束。
- **数据 CSV**导出当前模式的全部传播点，稳定性视图则导出各热焦距的扫描原始值；**SVG / PNG**导出当前图形。稳定性纵轴初始为 ±1.5，底层数据没有截断，可缩放看全。
- 当前分析采用轴对称标量模型，T=S。尚无任意腔型编辑、T/S 像散分离、双折射走离或完整三维热模型。对照 Rezonator 的 `CausticFunction.cpp`、`AbcdCalculator.cpp` 和上游参考计算校验，不宣称完整功能等同。

### 数值模型的范围

- 当前对话式设计求解器支持端泵直线腔，采用平面输入镜与凹面输出镜，扫描曲率、物理腔长、晶体位置。环形 / 折叠腔会提示当前模型不适用。
- ABCD 传播保留晶体前后平面折射和完整物理长度。复合晶体端帽参与光程；阈值增益只使用掺杂段长度。
- 内置 YVO4 折射率取自 [CRYSTECH Sellmeier 数据](https://www.crystech.com/Laser_Crystal/446.html)，π 偏振和相同端帽折射率作为明示假设，不能替代具体晶体证书。
- 冷腔按 1/e² 强度半径画图。热透镜扫描在晶体几何中心插入薄透镜并往返两次，是场景敏感性分析，不是由泵浦瓦数推得的热模型。
- 光纤泵浦的薄透镜共轭成像默认镜间距为 f1+f2，也可输入已经固定的位置。已有透镜只有曲率时，准直焦距保留待测。可补充实测焦距，或提供薄平凸处方及泵浦波长下的折射率。芯径或 NA 缺失时，工作台仍显示能由已知焦距确定的坐标。芯径和 NA 都已知时，旧设计入口的包络以二者均填满为前提；可用实测光束或逐条光线资料检验这一假设。
- 模式目标未知时，以 150 μm 为探索假设。搜索对全部可行离散几何评分，再保留不同曲率的优选项。输出镜默认 T=5% 起始方案，可采用匹配库存的真实 T，同时给 1/3/5/10% 阈值增益比较。页面的“综合最优候选”指给定范围、目标和假设下的排序第一；最大输出功率和效率尚需吸收、增益、损耗模型。
- 当前运行的是独立实现的 Python / NumPy ABCD 内核，仓库附带 Rezonator 源码并不表示正在运行其 C++ 程序。回归测试使用 Rezonator 自带 `calc/rezonator.py` 校验导出冷腔的稳定参数与束宽。
- 镀膜按明确波段匹配。AR880 不等于 AR808。库存排除损坏和无可用数量的器件，缺失规格列为待核验；空库给采购规格，不捏造已有器件。

## 0. v2.0 变了什么

**v1 是"会查资料、会写文档的 AI 助手";v2 是"会算物理、认识你实验室元件的工程伙伴"。**

v1 里所有结论都来自大模型的语言生成——包括那些看起来像数字的部分。v2 引入了一层**确定性物理内核**:谐振腔、相位匹配、镀膜、功率曲线全部由公式算出来,LLM 只负责理解你的需求、编排工具、解释结果。

核心原则(贯穿整个 v2):

| | 谁来做 | 为什么 |
|---|---|---|
| 物理量(角度、束腰、阈值、反射率) | **确定性计算** | 大模型会非常自信地编一个看起来合理、实际错误的数字,你根本看不出来 |
| 取舍判断(差一点能不能凑合) | LLM + 你 | 但必须**站在算好的数字上**,不是拍脑袋 |
| 最终拍板 | **你** | 系统给的是可审计的依据,不是命令 |

还有一条贯穿全篇的态度:**不知道就说不知道**。系统宁可告诉你"需实测",也不会给你一个编造的数。

## 1. 启动

**前置要求**(只需装一次):

- [Python 3.11+](https://www.python.org/downloads/)——安装时务必勾选 "Add python.exe to PATH"
- [Node.js 22 LTS](https://nodejs.org/)

装好后双击仓库根目录的 **`Launch-BeamWeft.bat`**。它会检查环境、装依赖、起后端(:8000)和前端(:5173)、等服务就绪后自动开浏览器。关掉弹出的两个黑窗口即停止。缺 Python/Node 或安装失败时,窗口会用中文告诉你原因并停住(不会闪退)。

再次双击启动器会连接已经打开的工作台，运行中的 Agent 和现有浏览器页可以继续工作。主工程目录与独立工程窗口现在共用生产版界面。首次打开或前端源码变化后需要构建一次，此后使用本地构建缓存。若更新了程序或配置，启动器会指出仍在使用的旧端口。先保存已有工作、等运行中的任务结束，再关闭旧服务并打开新版。

**首次运行会自动生成配置文件 `.env`**(在仓库根目录,记事本就能打开)。没配模型 key 时是演示模式:页面顶部会有黄色横幅提醒「演示模式」,此时 AI 输出全是固定模板,物理计算不受影响。

### 在首页配置 Agent（v2.3 新增）

首页 → **Agent 配置** → 选择模型服务商 → 选择或填写模型 ID → 粘贴 API Key → **保存并应用**。

- API Key 默认隐藏，点击「显示／隐藏」切换本次输入的可见性。保存后输入框会清空，已有密钥不会回显；以后只改模型时，密钥留空即可沿用。
- 支持 DeepSeek、通义千问、智谱 GLM、Kimi、OpenAI 兼容接口和 Anthropic Claude。模型 ID 支持手动填写，以服务商实际开放给账号的模型为准。
- 使用兼容服务或代理时，展开「高级设置 · 接口地址」填写 Base URL；填基础 API 路径，不含 `/chat/completions`。
- 保存后下一次 Agent 对话、计划、排查和报告生成即使用新配置，无需重启。保存成功表示本地配置已写入，密钥权限与模型可用性在实际调用时验证。
- 配置保存在后端 `UPLOAD_DIR/.agent-settings.json`，启动器默认放在 `%USERPROFILE%\LaserClaw-Data\uploads`，随数据目录保留。文件包含密钥，不应提交到代码仓库。首页保存的字段优先于 `.env`；未保存过的字段继续使用 `.env`。切换服务商会保留各自已保存的密钥与模型。

### 通过 `.env` 配置模型（可选）

用记事本打开根目录的 `.env`(首次启动已自动生成),设置(四选一):

```
AI_PROVIDER=deepseek
DEEPSEEK_API_KEY=sk-你的key
```

可选值:`deepseek`(深度求索)、`qwen`(阿里通义千问)、`zhipu`(智谱 GLM)、`moonshot`(月之暗面 Kimi),另外仍支持 `openai` / `anthropic` / `mock`。

STRICT_PROVIDER=true

否则 key 配错时系统会**静默回退到 mock 假数据**,你会以为在用真模型。开了这个开关就会直接报错。

> v2.0 起,无论从哪个目录启动后端,都会正确读到仓库根目录的 `.env`(以前从 `backend/` 启动会读不到,导致**明明配了 key 却静默用 mock 假数据**)。

## 2. v2.0 新增功能全览

### 2.1 元件库(全新页面)

**解决的问题**:以前 AI 给你出实验方案,不知道你实验室实际有什么;现在它知道。

**怎么用**:

1. 导航栏 → **元件库** → 选择你的元件清单 xlsx(如"127镜片统计")→ 导入
2. 系统会把每一行的**镀膜字符串拆解成结构化数据**。比如
   `S1:1064-1066HR, 1176-1180 T=20%`
   会被拆成两条记录:`S1 面 / 1064–1066nm / HR` 和 `S1 面 / 1176–1180nm / 部分透过 20%`
3. 导入完成会显示三个数字:**导入条目 / 镀膜段 / 待复核**

**关于"待复核"**:凡是系统读不懂或你自己写了"切向未知""不能确定是否镀膜"的行,都会进这个队列,**原始文字完整保留**。勾选筛选区的"待复核队列"就能只看这些。系统绝不会替你猜。

**筛选**:可以按 `波长 + 功能` 精确筛(这是数据库级查询,不是关键词搜索)。比如填 1064 + HR,只会给你在 1064nm 真正是高反的镜子——而不是"名字里带 1064"的镜子。

### 2.1.5 借出 / 归还 / 标损坏

元件表最后一列是**借用 / 状态**,解决的是"这块镜子明明在库里、上台一找发现在别人手上"。

- **借出**:点「借出」→ 填谁拿走了(本地版没有登录,名字就是唯一的线索)→ 可选填用途。
  数量列会变成 `可用 / 总数`(比如 `2 / 3`),行里出现一个「张三 ×1」的标签和「归还」按钮。
- **归还**:点「归还」→ 确认 → 系统会**顺便问一句"有没有损坏"**。归还时才是真正发现损坏的时刻,
  不必再去找一个单独的入口。归还记录**不会删**,以后要查"上次坏掉时是谁在用"能查得到。
- **标损坏**:随时可以标,可以写一句说明(鼠标停在「人工标记」标签上能看到)。

三件事必须知道:

1. **清单中元件的库存数量等于工作簿里写的数**。借出不去动它,可用量是算出来的。
   否则你下次重新导入 xlsx,借出账会被静默清掉、库存凭空变多。
2. **你标的损坏不会被重新导入冲掉**。人工标记和从表格文字里解析出来的状态分开存,人的判断优先。
3. **借出去的、标损坏的元件不会出现在匹配结果里**,淘汰理由会写明是「元件标注损坏」还是
   「可用数量不足(需 1,库存 3,已借出 3)」——不会给你推荐一块正躺在别人抽屉里的镜子。

**有元件没还的时候,既不能重新导入同一个文件,也不能删除这个批次**(都会提示"还有未归还")。
请先完成归还，避免新清单的数量或规格与正在借出的元件冲突。删除批次会连借用历史一起删除。

**同名文件重新导入会保留元件编号、人工损坏标记和已归还的借用历史。** 系统按名称与原始规格对应条目，
重复规格再按存放地、保管人、厂商区分，所以在 Excel 中排序不会把损坏标记转移给别的元件。
若带人工记录的条目无法对应，整次导入会取消并说明原因。最新清单中移除的条目若有人工状态或借用历史，
会保留在库中、数量置零；再次出现相同条目时沿用其原有记录。

### 2.2 元件匹配(按需求找元件)

**解决的问题**:"我要一块 1064 高反、曲率 400、口径至少 25 的镜子,库里有吗?"

在元件库页面填需求 → 开始匹配。系统对**每一件**库存逐参数判定,输出三类结果:

- **入围 / 前沿**:能用。"前沿"= 在所有维度上没有被其他候选全面超越的那几个,是你真正该在里面挑的
- **需实测**:可能能用,但依据不足。会明确告诉你**要测什么**
- **淘汰**:硬伤。页面底部会给"淘汰原因分布",让你知道是曲率不对、口径不够,还是镀膜不匹配

**三态判定是这套系统的精髓**,举个真实例子:

> 你需要 1064nm HR,库里有块标称 **1123nm HR** 的镜子。
> 系统不会简单说"不匹配",也不会假装能用,而是:调用薄膜物理内核算出这类镀膜的典型阻带约 1007–1269nm → 1064 落在里面,距离边缘 57nm → 判定 **"可能能用,需实测"**,并注明这是基于标准膜系的**物理先验,不是这块镜子的实测曲线**,上台前请测反射率。

反过来,如果某块镜子标称 **R=85%** 而你要求 R≥99.5%(在匹配表单的「反射率下限 R ≥ (%)」框填 99.5),系统会**直接淘汰**并说明"标称反射率 85% < 需求 99.5%"——不会因为"它也叫 HR"就放行。不填反射率下限时只按功能(HR/AR/PR)匹配,不做反射率硬判定。

### 2.2.5 实验计划会自己把腔设计出来(v2.0 关键能力)

新建工程只需填写名称。进入工作台后，再在光路中设置已知元件和波长，或把设计目标与已有器件告诉 Agent。下面是线性腔设计工具在有激光波长和相应模型条件时的一种搜索方法。

- 你**给了**腔镜曲率 → 扫描腔长,给稳区和推荐几何
- 你**没给** → 它**自己搜索**:遍历候选曲率 × 腔长(上千到上万种组合),两级排序挑出可实际搭建的几何。
  **候选曲率优先取自你导入的元件库**——不会推荐你没有的镜子。

这个比较按模型算出的热透镜裕度排序。在线性腔中，`m = 2·g₁g₂ − 1`，仅凭 |m| 选出的候选对热透镜可能有不同的耐受度。计算在增益介质处加入等效薄透镜，扫描光焦度直至失稳。要把这个结果同实验台上的泵浦条件对应起来，还需要热透镜测量或经过验证的热模型。下表使用同一对 R = 400 mm 的镜子。

| 腔长 | 冷腔 \|m\| | 模型可承受的热透镜光焦度 |
|---|---|---|
| 120 mm | 0.012 | **4.4 D** |
| 685 mm | 0.016 | **0.6 D** |

两者按 |m| 看几乎一样"安全",实际差 7 倍——所以旧的 |m| 判据被废弃了。

算出的数字会作为**权威数值**写进计划正文。真实例子(用户只说"想搭 808 泵浦 Nd:YAG 1064、
腔内 LBO 倍频到 532、输出 >1W,我只有库存里这几片镜子"):

> 推荐 R1=**R=500mm**、R2=**平镜**,腔长 **85.0mm**;冷腔束腰 **w0=0.24948mm**;
> 热透镜裕度 **8.3 D**(即 f≥120.5mm 时仍稳定)。
> 元件摆位:M1 @ **0.0mm** → 晶体入口 **20.0mm** → 晶体出口 **30.0mm** → M2 @ **85.0mm**。
> LBO type-I 1064→532 相位匹配:xy 面 **θ=90.0°, φ=11.36°**(另有 xz 面解 θ=32.48°)。
> 搜索空间:实验室库存曲率,评估 1413 种几何,其中 552 种稳定。

搜索过程可审计:计划页顶部会有一块绿框的**「物理内核计算结果」**,展示推荐几何、热透镜裕度、元件摆位、备选方案、搜索空间和边界提醒——这些是确定性计算,和 LLM 写的文字明确分开。如果内核没跑(比如没填波长),计划页会出现**红色警示**告诉你计划里的数字未经内核验证。
仍未纳入排序的因素——泵浦光斑与基模的重叠(模式匹配)、镀膜损耗、热透镜的像散与高阶项,这些仍需你上台核实。

### 2.3 物理计算模块(4 个)

在**案例 → 模块** tab,下拉框分成"测量分析"和"物理计算"两组。物理计算这 4 个都是纯公式,不经过大模型:

#### 谐振腔设计(cavity_design)
给腔镜曲率(和可选的晶体参数),它扫描腔长找出**稳定区间**,推荐一个腔长,并给出**每个元件从 M1 起的毫米级摆放位置**、各面光斑大小和**实测热透镜裕度**。

摆位表上方会画一张**摆位图**:M1、晶体、M2 按**真实横向比例**摆在一条光轴上,镜面的凹凸朝向就是实际朝向,
中间是冷腔基模的光束包络,束腰位置单独标出来。纵向(光斑半径)会**放大几百倍**才看得见——
放大倍数写在图下面那行小字里,不会让你把图上的粗细当成真实尺寸。
图里不含热透镜,是冷腔;这也写在图下的说明里。

推荐依据:填了目标束腰按束腰匹配;没填则按**实测热透镜裕度最大**(和实验计划的搜索一致,不用 |m| 代理判据)。

参数可以**完全留空**——自动读案例参数,腔长没给时自动扫描 30–800 mm。什么都没填时会用中文提示你至少要给腔镜曲率。也可以填:
```json
{"R1_mm":"flat","R2_mm":500,"L_scan_mm":{"start":100,"stop":600,"step":10},"target_waist_mm":0.25}
```

#### 相位匹配(phase_match)
算 SHG/SFG 的相位匹配角与走离,支持 BBO / LBO / KTP / BiBO。
```json
{"crystal":"lbo","lambda1_nm":1064,"pm_type":"I"}
```
和频(如 1064+532→355)加一个 `"lambda2_nm":532` 即可。

#### 镀膜评估(coating_tmm)
三种模式:知道膜系 → 精确算;有厂商曲线 → 直接用;**只有标称波长 → 给诚实的原型估计**(带阻带区间、置信度、"建议实测"标记)。
```json
{"nominal":{"function":"HR","design_wavelength_nm":1123},"query_wavelengths_nm":[1064]}
```

#### 元件匹配(component_match)
就是 2.2 的能力,挂在案例里,结果会存进案例的审计轨迹。

### 2.4 功率曲线(v2 新增的测量模块)

**这是你日常最常用的测量**:不同泵浦功率下的输出功率。

**怎么用**:加一个"功率曲线"模块 → 上传两列数据文件(泵浦, 输出),支持 `.csv` / `.txt` / `.tsv`,逗号/制表符/空格分隔都行。或者在参数里内联:
```json
{"output_coupler_T_pct":5,"label":"T=5% 输出镜","data":{"pump":[...],"output":[...]}}
```

**它会自动算出**:
- **阈值泵浦功率**和**斜率效率**(自动识别线性区,用整段折线拟合,不会被数据尾巴带偏)
- 带坐标刻度、实测数据点、阈值标记的拟合图

**跨曲线分析(重点)**:如果你给同一个案例测了**多个不同输出镜透过率**的曲线,并在参数里标了 `output_coupler_T_pct`,系统会自动做:
- **Findlay-Clay 分析** → 反推**腔内往返损耗**
- **Caird 分析** → 反推**本征斜率效率**

也就是说,你日常的例行测量数据,直接就能算出腔内损耗——这是以前要手动画图拟合才能得到的量。

**关于警告**:如果数据不是典型的阈值曲线(比如高低泵浦段斜率不一致 = 热翻卷),系统会**明确警告**而不是给你一个漂亮但错误的阈值。看到警告请认真对待。

### 2.5 Agent 现在会真的调用工具

以前在 Agent 里说"设计个腔",它会写一段文字。现在:

> 你说:**"帮我设计一个谐振腔,扫描腔长找到稳区,算出束腰和元件摆放位置"**
>
> 系统:识别意图 → 制定 4 步计划 → 检索知识库 → **调用腔设计工具真算** → 结果+引用存档

聊天里会显示三种标签:**路由到哪个工具**、**任务编号与状态**、**📎 引用了哪些文档**。案例的 Agent tab 里能看到完整轨迹:每一步、每个工具调用、耗时多少毫秒。**全程可回放、可审计。**

也可以在案例的 Agent tab 里直接从下拉选模式(谐振腔设计/相位匹配/镀膜评估/元件匹配/功率曲线分析等)。

### 2.6 文献检索(三个入口)

**解决的问题**:选晶体、查相位匹配角、找先例参数都要翻文献,以前得离开 BeamWeft 去各个网站搜。

数据来源是 **OpenAlex**(期刊元数据+摘要+被引数)和 **arXiv**(物理预印本),都免费、免注册、国内可直连。
三个入口,结果完全一致:

1. **资源 → 文献检索**:不用建案例,填检索词直接查。查完可以「存入案例」——会在那个案例里
   建一个文献检索模块并存档结果。
2. **案例 → 模块 → 文献检索**:和其他模块一样,检索词留空会自动用案例的波长/晶体拼一个;
   结果存档后**自动进入案例知识库**,之后生成实验计划/报告时可以引用到这些文献。
3. **Agent 对话**:直接说「帮我找几篇 LBO 相位匹配的文献」,系统会自动路由、把你句子里的
   主题词拿去检索,结果存到关联案例。

每条结果带标题(可点开原文)、作者、年份、期刊、被引数、摘要(折叠),支持一键**导出 BibTeX**
(写论文时直接粘进 .bib 文件)。

三件事必须知道:

- **检索词建议用英文**——激光领域的文献库以英文为主,中文词查 OpenAlex/arXiv 基本查不到东西。
- **查到 ≠ 读过**。系统拿到的是元数据和摘要,没有读任何论文全文;摘要只够初筛,采信结论请打开原文。
  这句声明会跟着结果一起显示(打印也在)。
- **中文文献(知网/万方)没有公开合法的接口**,系统不做爬虫。中文文献请在知网导出后自行整理,
  后续版本会支持 BibTeX/RIS 文件导入。

**Q:检索失败怎么办?** 每个源单独失败单独提示(比如 arXiv 连不上但 OpenAlex 正常,会给出
OpenAlex 的结果并注明 arXiv 失败了);全部失败会明确报错,不会假装"没有相关文献"。

## 3. 典型工作流:从零搭一个 1064 倍频腔

1. 在 **新建工程** 中输入名称。进入工作台后设置 1064 nm 波长，录入已知的晶体、腔镜与实验目标。待测的腔镜曲率可以留空。
2. **腔镜曲率留空的,先生成实验计划** —— 计划 tab → 生成。自动搜索只在这一步跑:系统遍历候选曲率 × 腔长,
   在绿色「物理内核计算结果」框里给出**推荐的 R1/R2 和腔长**。把推荐曲率记下来(想让后面的模块自动读到,
   也可以回「概览」把它填进腔镜曲率字段)。已经知道用什么镜子的,直接跳到第 3 步
3. **模块 → 谐振腔设计** —— 参数留空直接运行 → 拿到稳定区间、推荐腔长、摆位图与元件摆位
   (这个模块需要腔镜曲率:案例里填了就自动读,没填会用中文提示你——推荐曲率来自第 2 步)
4. **元件库 → 元件匹配** —— 用上面得到的曲率去库里找镜子 → 看哪些能用、哪些需实测
5. **模块 → 相位匹配** —— 确认倍频晶体的切角
6. **模块 → 镀膜评估** —— 核查候选镜子在 1064/532 各波长的表现
7. 上台搭建,把"需实测"清单上的项目测掉
8. **模块 → 功率曲线** —— 传测量数据,拿阈值和斜率效率;换个输出镜再测一条 → 自动出腔内损耗
9. **Agent → 生成实验报告** —— 所有模块结果和引用都在案例里,报告有据可依

**带进实验室**:在案例页按 `Ctrl+P`(Mac 是 `⌘+P`)→ 目标选「另存为 PDF」或直接打印。
导航栏、按钮、折叠区会自动去掉,白底黑字,摆位图和功率曲线是矢量的,放大不糊。
台子边上不一定有电脑,纸更靠谱。

## 4. 必须知道的边界(诚实清单)

这些不是 bug,是明确标注的适用范围:

- **双轴晶体相位匹配**(LBO/KTP/BiBO)用主平面近似,标注为 `medium` 置信度。下单前请和厂商确认切角
- **标称镀膜的阻带估计**是基于"标准膜系"的物理先验,**不是你那块镜子的实测曲线**。凡是标了"需实测"的,上台前请真的测
- **腔内有晶体时,束腰的"位置"是光程坐标**(尺寸精确)。要物理位置请看各面光斑列表
- **系统不控制任何硬件**。它是工作流与计算助手,不是控制系统
- **LLM 生成的文字部分**(实验计划、排故建议、报告)仍是启发式的,需要你判断。但**所有数字**来自确定性计算

## 5. 常见问题

**Q:参数框必须写 JSON 吗?**
不必。物理计算模块留空就能跑(自动读案例参数)。要覆盖时,点"参数示例"折叠区抄一条改。

**Q:元件库导入需要什么权限?**
本地默认部署(`REQUIRE_AUTH=false`)下直接可用,不需要任何操作。只有管理员开启了 `REQUIRE_AUTH=true` 的多人部署才需要 reviewer 账号。

**Q:元件库里"待复核"的行怎么办?**
那是系统读不懂或你原表就标了"未知"的行。原始文字都在，你可以在原 xlsx 里补全后重新导入。
如果该条目已有人工状态或借用历史，改变名称或规格可能触发“无法对应”提示；请核对这些身份字段，避免把历史记到另一件元件上。

**Q:改了文件名重新导入,元件变成两份了?**
是的——不同文件名会当成不同批次累加。在元件库页面的「导入批次」列表里删掉旧批次即可。

**Q:提示"还有未归还的元件",不让我重新导入?**
先把借出去的元件点「归还」，再导入。同名文件刷新会保留元件编号和历史，但必须先完成借出账目核对。

**Q:方案能打印或存成 PDF 吗?**
能。在案例页按 `Ctrl+P`(Mac `⌘+P`),选「另存为 PDF」。导航栏和按钮会自动隐藏,白底黑字,图是矢量的。

**Q:更新到新版本后要做什么?**
双击 `Launch-BeamWeft.bat` 就行,数据库会自动补上新版本加的字段,原来导入的元件和案例都在。
v2.2.1 还会修正旧附件路径，让迁移后的文件从数据目录读取。修正前的数据库备份为
`%USERPROFILE%\LaserClaw-Data\laserclaw.db.before-upload-paths.bak`。已有方案若需要使用本次修复后的检索证据，请重新生成。
(用 Docker 部署的多人版仍然按 `alembic upgrade head` 走。)

**Q:功率曲线要几条才能算腔内损耗?**
至少 2 条不同输出镜透过率的曲线。但 2 条时 R²=1 是数学必然、没有意义,系统会提示你"建议再测一组"。3 条起结果才可信。

**Q:界面能切英文吗?**
右上角 EN 按钮,全站双语。
